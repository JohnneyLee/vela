# Vela 已实现功能与后续可做

对应试用版本约 **0.1.3**（安装包 `Vela_0.1.3_x64-setup.exe`）。安装目录：`%LOCALAPPDATA%\Vela\`。

---

## 一、到目前为止已实现

### 1. 划词入口与结果卡

| 能力 | 说明 |
|------|------|
| 选区检测 | 拖选 / 双击 / 三击 / Shift+点 / Shift+方向键等手势后出入口 |
| 小入口图标 | 品牌色圆标 +「V」；默认较醒目；靠近略放大 |
| 先选后执行 | 点图标 → 取词并打开结果卡 → **点顶部「译 / 释 / 润 / 读」才发起请求** |
| 推荐逻辑 | `suggest()` 仍可影响高亮习惯；默认不再自动跑推荐动作，避免浪费 tokens |
| 关闭入口 | Esc、点别处、右键、滚轮、其它按键 → 收起入口，事件放行 |
| 结果卡四模式 | 译 / 释 / 润 / 读，可在卡片内切换 |
| 关闭结果 | × 或 Esc，清掉本轮原文与译文 |

### 2. 取词

| 能力 | 说明 |
|------|------|
| UIA 取词 | 不碰剪贴板；对 Electron 会搜子树 TextPattern |
| 模拟复制 | 备份剪贴板 → 复制 → 读文本 → 还原；Electron 含渲染窗 WM_COPY、扫描码等路径 |
| 快捷键取词 | 默认 `Ctrl+Alt+T`（以设置为准） |
| 翻译剪贴板 | 默认 `Ctrl+Alt+Shift+T`，可改 |
| 手动输入 | 结果卡内输入后回车 |
| 静默预取词 | **默认关闭**；调试可用 `%APPDATA%\com.vela.desktop\prefetch-debug.json` |
| 终端 | 不自动出入口，降低误 Ctrl+C 中断风险 |
| 可编辑场景 | 出入口略延迟（约 500ms），减轻「选中为了删除」的打扰 |

### 3. 翻译与引擎

| 能力 | 说明 |
|------|------|
| 机器翻译 | Google、MyMemory、DeepL、离线 OPUS-MT |
| AI | 免费公共服务、DeepSeek、OpenAI、Moonshot、Gemini、Ollama |
| 多 Key / 厂商 | OpenAI 兼容适配、预置厂商、Key 存 Windows 凭据（DPAPI） |
| 显示方式 | 对照 / AI 优先 / 机器优先 / 自动 |
| 母语 | 中 / 英 / 日，影响自动方向 |
| 完全本地 | 仅离线 MT + Ollama |
| 连接测试 | 设置里可测 AI 连接、探测 Ollama |

### 4. 解释 / 润色 / 朗读

| 能力 | 说明 |
|------|------|
| 解释 | AI 解释含义、词性等（按母语出说明） |
| 润色 | **预设 4 个**（只改错误 / 通顺自然 / 大幅重写 / 压缩变短）+ **自定义要求** |
| 润色对比 | 逐词 diff；「为什么改」说明改动 |
| 朗读 | 读结果或原文 |
| 写回 | 可编辑目标可「替换」；支持撤销 |

### 5. 截图与 OCR（路线图内已推进部分）

| 能力 | 说明 |
|------|------|
| 截图翻译 | 框选画面 OCR 后走翻译流（含引擎选择） |
| 钉图 | 可拖动、带关闭等基本交互 |
| OCR 结果展示 | 尽量不挡原文（侧方/下方卡片） |
| 权限 | Tauri 2 capabilities 已覆盖 overlay / screenshot 等命令 |

### 6. 设置与体验

| 能力 | 说明 |
|------|------|
| 主题 | 系统 / 浅 / 深 / 护眼绿 / 暖色 |
| 设置窗 | Esc、统一关闭；AI 引擎列表可展开编辑 |
| 隐私相关 | 允许部分剪贴板备份等开关；日志不写选区正文 |
| 单实例 / 托盘 / 开机启动 | 插件侧已具备（以设置为准） |
| 安装包 | NSIS：`npm run tauri build` → `Vela_*_x64-setup.exe` |

### 7. 明确不做或默认不做的（当前）

- 默认**不会**在每次选中时静默 Ctrl+C。
- 不会在未点「译/释/润/读」时自动烧 AI tokens。
- API Key **不**进设置 JSON、不进对话日志（由用户自填凭据库）。

## 二、还可以做的功能（按优先级大致排序）

### P0 — 稳定性与试用反馈

| 项 | 说明 |
|----|------|
| 试用反馈收集 | 让试用者反馈：Cursor/浏览器/微信等取词成功率、误触、图标可见性 |
| 取词失败文案 | 区分「未开启预取」「超时」「剪贴板被占用」等，并提示快捷键 |
| 空选区整行复制防护 | 识别 VS Code 系「空选复制整行」并丢弃 |
| 终端误中断 hardening | 检测前台是否终端面板，强制禁用任何 Ctrl+C 预取 |

### P1 — 入口与场景策略

| 项 | 说明 |
|----|------|
| 按应用配置出现方式 | 自动小图标 / 延迟 / 仅热键 / 不出现；设置页「高级」管理 |
| 代码编辑器策略可调 | 当前编辑器仍出图标；可改为「仅热键」选项 |
| 热键直通四动作 | 选中后一键译/释/润/读，不经图标 |
| 首次引导 | 更短的一次气泡或设置向导 |
| 「点图标直接执行推荐」 | 设置项，默认关（给求快的用户） |

### P2 — 润色与 AI

| 项 | 说明 |
|----|------|
| 自定义要求历史 | 最近几条本地记住，一点即用 |
| 预设可编辑 | 用户增删自己的预设文案 |
| Ollama 模型列表 | 拉 `/api/tags`、冷启动提示 |
| 流式体验与取消 | 生成中可停；错误可重试 |

### P3 — Cursor / VS Code 伴侣扩展（长期最稳取词）

| 项 | 说明 |
|----|------|
| 本机 bridge | 扩展在 127.0.0.1 随机端口 + 令牌文件；Vela 按需询问选区 |
| 安全 | 仅本机、必带令牌、拒带 Origin 的请求；扩展开源极简 |
| 覆盖范围 | 代码编辑区为主；AI 聊天面板 / 终端另议 |
| 安装引导 | 检测到 Cursor 时提示安装扩展 |

### P4 — 其它增强

## 三、和旧 README 的差异（便于改官网/说明）

旧 README 仍写「选中后旁边出现译/释/润/读四按钮」「润色三档力度」「暂无截图」。当前产品更接近：

- 选中 → **小图标** → 结果卡 → **再选** 译/释/润/读；
- 润色 = **少量预设 + 自定义要求**；
- 截图 OCR 已有能力（完整度以实机为准）；
- 版本试用包为 **0.1.3**。

发试用时可附一句：安装后若托盘无图标，看 `%LOCALAPPDATA%\Vela\vela.exe` 是否在运行；与旧版同目录，安装会覆盖。

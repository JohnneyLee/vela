# Vela Windows 发布验收清单

用于发布前回归。自动检查和必须在真实 Windows 桌面验证的项目分开记录；服务端故障、权限、剪贴板和 WebView 多窗口行为不能只靠单元测试判定。

## 1. 自动化检查

- [ ] `npm run build`：前端构建成功。
- [ ] `cargo test --manifest-path src-tauri/Cargo.toml`：Rust 单元测试全部通过。
- [ ] `cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets`：记录警告数量；新增不安全代码、错误或未使用代码须清零或说明。
- [ ] `npm run tauri build`：生成 Windows x64 NSIS 安装包；若启用更新器，同时生成签名更新产物。
- [ ] 发布版本在 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`、Release 标签和更新清单中一致。
- [ ] 对源码与安装包做隐私扫描：不包含 updater 私钥、API Key、测试文本或调试密钥。

## 2. 安装、设置与多窗口状态（真实 Windows 手动）

- [ ] 在已有安装上覆盖安装新版；设置、DPAPI 保存的 API Key 和离线模型仍保留。
- [ ] 同时打开设置窗口和翻译卡片。在设置窗口依次切换机器翻译与 AI 引擎，保存后卡片下拉框及时显示相同选择。
- [ ] 在卡片选项中切换机器翻译与 AI 引擎，设置窗口也及时显示相同选择；关闭并重开两个窗口后仍一致。
- [ ] 重复快速切换、改变其他设置、关闭其中一个窗口后再修改另一个窗口设置；不得由旧状态覆盖新值。
- [ ] 设置页与卡片都监听 `translation-engines-changed`；切换任一端后，另一端更新并持久化同一值。

## 3. 翻译引擎路由（真实 Windows 手动；需要联网服务）

- [ ] 选择 Google，成功响应时结果标签显示 Google；选择 MyMemory，成功响应时显示 MyMemory。
- [ ] 选择 Google 后临时阻断 Google 域名但允许 MyMemory：应显示 Google 请求错误，且不得向 MyMemory 或离线引擎回退。
- [ ] 选择 MyMemory 后临时阻断 MyMemory：应显示 MyMemory 请求错误，不得显示 Google。
- [ ] 选择 DeepL 并配置 Key：DeepL 只出现在机器翻译选项，不能作为 AI 引擎选择；译文标签显示 DeepL。
- [ ] 选择 Ollama：确认请求只到本机 Ollama 地址，模型选择与结果标签对应。
- [ ] 检查卡片实际显示的服务标签与网络目标一致；仅检查下拉框不足以证明请求路由正确。

## 4. 隐私与本地模式（真实 Windows 手动）

- [ ] 云端引擎翻译时，确认原文只发往当前所选服务；设置文件、日志和错误提示不包含原文、译文或完整 Key。
- [ ] 确认 API Key 在 Windows 凭据/DPAPI 存储中；搜索 `settings.json` 和日志，不应出现 Key。
- [ ] 完全本地模式开启且离线模型已预装、Ollama 正常时翻译；用 Windows 防火墙日志或网络监控确认没有外网连接。
- [ ] 单独验证模型缺失时的首次下载行为：离线模型获取会连接模型托管站点；不要把首次下载测试误报为翻译文本上传。
- [ ] 检查取词日志仅含允许的诊断元数据，并确认过期日志按保留策略删除。
- [ ] 检查生产 WebView 使用预期 CSP；验证设置页链接、Ollama 本机连接及所需功能正常，禁止未批准的脚本/网络来源。

## 5. 取词、剪贴板与写回（真实 Windows 手动）

- [ ] UIA 可用应用取词不改变剪贴板；不点击入口时剪贴板保持原值。
- [ ] 复制回退成功后原剪贴板内容和格式恢复；剪贴板繁忙、备份失败、允许部分备份开关分别验证。
- [ ] 测试浏览器、Office、Cursor/VS Code、终端及管理员权限应用；终端中不得因自动取词误发 Ctrl+C 中断程序。
- [ ] 通过剪贴板快捷键翻译时读取预期内容；多次触发不得串词或留下翻译文本。
- [ ] 写回前切换焦点到同一应用的另一个输入框，确认程序阻止错误位置写入，或明确提示目标失效；随后验证替换和撤销。

## 6. 截图 / OCR / 显示（真实 Windows 手动）

- [ ] 单屏、多屏及不同 DPI 下框选区域位置正确，Esc 可取消。
- [ ] 清晰文本、多行、低对比文本与受保护窗口分别检查 OCR 结果和错误提示。
- [ ] OCR 结果按已选机器/AI 引擎请求；结果标签、顺序和失败隔离正确。
- [ ] 钉图可拖动、关闭；OCR 结果卡不遮挡主要原文区域。

## 7. 更新器（需更新器集成、签名密钥与 GitHub Release）

- [ ] 用户点击「检查更新」时才发起检查；页面显示检查状态和当前版本。
- [ ] 无更新时显示已是最新；有更新时显示版本与说明，未确认前不得下载或安装。
- [ ] 用户取消、断网、下载失败时不影响当前应用。
- [ ] 签名有效的更新可安装并重启；签名篡改/不匹配必须拒绝安装。
- [ ] 更新后用户设置、Key 和离线模型保留；旧版本无法被误判为更新或降级。
- [ ] 验证公开更新检查不附带翻译文本、API Key 或用户标识；只产生访问 Release 清单/产物所需的连接元数据。

**待人工验收**：签名 Release、GitHub Actions Secrets 配置和真实 Windows 更新安装流程仍需发布方验证；源码测试不能替代这些检查。
